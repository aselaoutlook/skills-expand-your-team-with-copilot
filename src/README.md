# Mergington High School Activities

This website helps students explore extracurricular activities at Mergington High School, while giving teachers simple tools to manage student registrations.

## Current Website Experience

- Browse a list of activities with descriptions, schedules, current participants, and remaining spots
- Search activities by keyword
- Filter activities by category, day, time, and difficulty level
- Share an activity with a direct link
- Switch between light mode and dark mode

## Teacher Tools

- Teachers can log in from the website
- Logged-in teachers can register a student for an activity
- Logged-in teachers can remove a student from an activity
